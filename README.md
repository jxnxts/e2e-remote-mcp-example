# Experimental remote MCP companion

A community experiment for trusted, cooperating executions of e2e through
MCP Streamable HTTP. This is experimental, with no official e2e support claim
or demonstrated security boundary between hostile tenants.

```sh
git clone https://github.com/jxnxts/e2e-remote-mcp-example.git
cd e2e-remote-mcp-example/contrib/community/docker-remote-mcp
```

Follow the [companion README](contrib/community/docker-remote-mcp/README.md)
for setup, usage and limits. Read the
[verification scope](contrib/community/docker-remote-mcp/VERIFICATION.md)
before relying on the results. No image was published and no service was deployed.

The reviewed files retain their original directory and bytes. See
[PROVENANCE.md](PROVENANCE.md) and [SOURCE-SHA256SUMS](SOURCE-SHA256SUMS).
